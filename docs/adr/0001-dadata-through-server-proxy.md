# DaData вызывается только через серверный прокси

Браузер не обращается к DaData напрямую, а ходит в собственные endpoints `/api/dadata/*` из `server.js`: токен и секретный ключ живут только в переменных окружения сервера, а клиенту уходят лишь нужные поля (ИНН, КПП, ОГРН, название, адрес). Прямой вызов из браузера проще, но раскрыл бы ключи, а секретный ключ стандартизации даёт доступ к платному методу.

## Consequences

- Без запущенного `server.js` поиск Клиента работает на тестовых данных с пометкой «тест», а проверка адреса недоступна; это сделано осознанно, чтобы прототип открывался как статическая страница.
- Стандартизация адреса платная, поэтому вызывается только по явной кнопке, а не при вводе.
