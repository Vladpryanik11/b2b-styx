# Кабинет и Заказы пока хранятся в localStorage

Прототип сохраняет Кабинет, Заказы и Корзину в `localStorage` браузера, чтобы сценарий можно было проверить без backend. Это демо-режим, а не production-хранилище: пароль хэшируется в браузере, в одном браузере живёт один Кабинет, а новая регистрация заменяет прежний вместе с Заказами.

## Consequences

- Любая production-функция (вход, Заказы, цены) должна переехать на сервер; UI не должен выдавать демо-сохранение за отправку Заказа поставщику.
- Суммы Заказа считаются в браузере по демо-каталогу; в production итог пересчитывает сервер.
