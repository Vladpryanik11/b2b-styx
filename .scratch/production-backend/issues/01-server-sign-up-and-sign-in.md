# 01: Регистрация и вход через сервер

**What to build:** Контактное лицо регистрирует Кабинет (Реквизиты Клиента из DaData, email, пароль) и входит в него с любого браузера; после выхода и входа с другого устройства видит тот же Кабинет.

**Blocked by:** None (can start immediately)

**Status:** needs-triage

- [ ] Пароль хранится только как Argon2id/bcrypt-хэш на сервере
- [ ] Сессия живёт в httpOnly cookie, а не в localStorage
- [ ] Повторная регистрация на тот же email отклоняется
- [ ] Один Клиент (ИНН) может иметь несколько Контактных лиц
