# STYX B2B

Личный кабинет оптового клиента STYX Natural Cosmetic: организация регистрируется один раз и дальше оформляет заказы с уже подставленными реквизитами.

## Участники

**Клиент**:
Организация (юрлицо или ИП), которая покупает продукцию STYX оптом. Определяется ИНН.
_Avoid_: компания, контрагент, покупатель, аккаунт

**Контактное лицо**:
Человек, который входит в кабинет от имени Клиента и оформляет заказы.
_Avoid_: пользователь, менеджер клиента

**Кабинет**:
Связка «Контактное лицо → Клиенты» с данными для входа. Одно Контактное лицо может работать от имени нескольких Клиентов (например, ООО и ИП одного владельца); в каждый момент выбран один Клиент или режим «Все юрлица».
_Avoid_: аккаунт, профиль, учётная запись

**Текущее юрлицо**:
Клиент, выбранный в переключателе в шапке Кабинета. Заказы, суммы и адреса показываются для него; в режиме «Все юрлица» — для всех Клиентов Кабинета сразу. В каждом Заказе юрлицо выбирается явно.
_Avoid_: активная компания, текущий аккаунт

**Реквизиты**:
Данные Клиента, которые нужны для документов: наименование, ИНН, КПП, юридический адрес.
_Avoid_: данные компании, карточка организации

## Каталог

**Товар**:
Позиция ассортимента STYX под одним названием, например «Лосьон „Водоросли“».
_Avoid_: продукт, SKU

**Вариант**:
Конкретная фасовка Товара (объём) со своим артикулом, ценой и наличием. Заказывают всегда Вариант, а не Товар.
_Avoid_: объём, фасовка, модификация

**Артикул**:
Код Варианта, по которому его ищут и учитывают.
_Avoid_: SKU, код товара

**Категория**:
Группа Товаров в каталоге (Лосьоны, Гели, Целло гели, Кремы).
_Avoid_: тип, раздел

## Заказ

**Корзина**:
Набор Вариантов с количеством, который Контактное лицо собирает до оформления Заказа.
_Avoid_: черновик

**Заказ**:
Оформленная Корзина с Способом получения, суммой и статусом, привязанная к Клиенту.
_Avoid_: покупка, сделка, заявка

**Позиция заказа**:
Один Вариант в Заказе с количеством и ценой на момент оформления.
_Avoid_: строка, товар в заказе

**Способ получения**:
Доставка (по Адресу доставки) или Самовывоз.
_Avoid_: тип доставки

**Адрес доставки**:
Куда везти Заказ. У Клиента может быть несколько сохранённых Адресов доставки (склад, салон, офис) с необязательным названием; один из них основной и подставляется в новый Заказ. Если сохранённых нет, подставляется юридический адрес.
_Avoid_: адрес клиента, юридический адрес

**Повтор заказа**:
Добавление Позиций прошлого Заказа в Корзину по текущим ценам.
_Avoid_: копия заказа, дубль

**Бланк заказа**:
Excel-файл STYX для одного юрлица STYX (Москва или Санкт-Петербург) с количеством по Позициям Заказа. Один Заказ Клиента превращается в один или два Бланка: Клиент их не видит, их получает менеджер STYX.
_Avoid_: счёт (счёт выставляет бухгалтерия по Бланку), накладная

**Менеджер**:
Сотрудник STYX с доступом к кабинету менеджера (`/admin`): подтверждает Клиентов, меняет статус Заказа, скачивает Бланки заказа. Заводится командой `node server.js create-manager`, сам зарегистрироваться не может.
_Avoid_: админ, оператор

**Заявка на кабинет**:
Состояние Клиента после регистрации, пока Менеджер не проверил организацию. Войти в кабинет до подтверждения нельзя; после подтверждения Клиенту приходит письмо.
_Avoid_: модерация, верификация

**Статус заказа**:
Новый → В работе → Отгружен → Завершён, или Отменён. Меняет Менеджер, Клиент видит в своём кабинете. «Не отправлен» бывает только у Заказа прототипа без сервера.
